# ☁️ 5 AWS Beginner Projects 

Welcome to my AWS hands-on lab repository! 

I built these 5 beginner-friendly cloud projects to practice my cloud computing skills. I am sharing my step-by-step guides here so others can learn too! 

## 🚀 The Projects

Click on any project below to read the full step-by-step guide and see the code!

### [Project 1: Host a Simple Website on Amazon S3](./project-1-s3-website)
* **What you will learn:** S3 Buckets, Static Website Hosting, and Bucket Policies.

### [Project 2: Launch a Web Server on EC2](./project-2-ec2-webserver)
* **What you will learn:** EC2 Instances, Security Groups (Firewalls), and basic Linux commands.

### [Project 3: Create Your Own Custom VPC](./project-3-custom-vpc)
* **What you will learn:** Virtual Private Cloud (VPC), Public Subnets, Internet Gateways, and Route Tables.

### [Project 4: Secure Web App with a Private Database](./project-4-secure-rds)
* **What you will learn:** Network Isolation, Private Subnets, DB Subnet Groups, and secure connection rules.

### [Project 5: Build a Serverless API](./project-5-serverless-api)
* **What you will learn:** AWS Lambda (Python), DynamoDB (NoSQL), IAM Roles, and Function URLs.
